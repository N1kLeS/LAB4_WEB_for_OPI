# Тест-кейсы

## TC-01

ID: TC-01

Название: Открытие страницы входа.

Предусловия: приложение запущено, пользователь не авторизован.

Шаги:
1. Открыть приложение.
2. Проверить видимость формы входа.

Тестовые данные: нет.

Ожидаемый результат: отображаются поля `username`, `password`, кнопка входа и ссылка перехода к регистрации.

## TC-02

ID: TC-02

Название: Переключение между входом и регистрацией.

Предусловия: открыта страница входа.

Шаги:
1. Нажать ссылку перехода к регистрации.
2. Проверить отображение кнопки регистрации.
3. Нажать ссылку возврата ко входу.
4. Проверить отображение кнопки входа.

Тестовые данные: нет.

Ожидаемый результат: пользователь может переключиться на форму регистрации и вернуться на форму входа.

## TC-03

ID: TC-03

Название: Ошибка при пустой регистрации.

Предусловия: открыта форма регистрации.

Шаги:
1. Оставить поля `username` и `password` пустыми.
2. Нажать кнопку регистрации.

Тестовые данные: `username = ""`, `password = ""`.

Ожидаемый результат: отображается ошибка авторизации, пользователь не входит в приложение.

## TC-04

ID: TC-04

Название: Успешная регистрация нового пользователя.

Предусловия: открыта форма регистрации, пользователь с таким именем отсутствует.

Шаги:
1. Ввести имя пользователя.
2. Ввести пароль.
3. Нажать кнопку регистрации.
4. Проверить отображение рабочей области.

Тестовые данные: уникальные `username`, `password`.

Ожидаемый результат: пользователь авторизован, отображаются кнопка выхода и canvas.

## TC-05

ID: TC-05

Название: Выход после регистрации.

Предусловия: пользователь зарегистрирован и авторизован.

Шаги:
1. Нажать кнопку выхода.
2. Проверить отображение формы входа.

Тестовые данные: уникальные `username`, `password`.

Ожидаемый результат: пользователь вышел из аккаунта, отображается кнопка входа.

## TC-06

ID: TC-06

Предусловия: пользователь зарегистрирован и вышел из аккаунта.

Тестовые данные: ранее созданные `username`, `password`.

## TC-08

ID: TC-08

Название: Пустая таблица результатов у нового пользователя.

Предусловия: новый пользователь зарегистрирован и авторизован.

Шаги:
1. Открыть рабочую область после регистрации.
2. Проверить таблицу результатов.

Тестовые данные: уникальные `username`, `password`.

Ожидаемый результат: отображается сообщение о пустой таблице результатов.

## TC-09

ID: TC-09

Название: Кнопка проверки заблокирована без валидной точки.

Предусловия: пользователь авторизован.

Шаги:
1. Не выбирать `X`.
2. Не вводить `Y`.
3. Не менять выбранный `R`.
4. Проверить состояние кнопки проверки.

Тестовые данные: `X` не выбран, `Y = ""`.

Ожидаемый результат: кнопка проверки заблокирована.

## TC-10

ID: TC-10

Название: Кнопка проверки активна после ввода валидной точки.

Предусловия: пользователь авторизован.

Шаги:
1. Выбрать `X`.
2. Ввести `Y`.
3. Выбрать `R`.
4. Проверить состояние кнопки проверки.

Тестовые данные: `X = 1`, `Y = 1`, `R = 2`.

Ожидаемый результат: кнопка проверки активна.

## TC-11

ID: TC-11

Название: Добавление результата с попаданием.

Предусловия: пользователь авторизован, таблица результатов пуста.

Шаги:
1. Выбрать `X`.
2. Ввести `Y`.
3. Выбрать `R`.
4. Нажать кнопку проверки.
5. Проверить первую строку таблицы.

Тестовые данные: `X = 1`, `Y = 1`, `R = 2`.

Ожидаемый результат: в таблице появляется одна строка со статусом `ПОПАДАНИЕ`.

## TC-13

Предусловия: пользователь авторизован, canvas отображается.

Шаги:

## TC-15

ID: TC-15

Название: Сохранение результатов после выхода и повторного входа.

Предусловия: пользователь зарегистрирован и авторизован.

Шаги:
1. Проверить точку.
2. Убедиться, что в таблице появилась одна строка.
3. Выйти из аккаунта.
4. Войти с теми же данными.
5. Проверить таблицу результатов.

Тестовые данные: `X = 1`, `Y = 1`, `R = 2`, ранее созданные `username`, `password`.

Ожидаемый результат: после повторного входа в таблице сохраняется одна строка результата.
